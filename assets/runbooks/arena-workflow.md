# Model Arena workflow

1. Open the Arena toolbar chip or an `*.nj-arena.json` file.
2. Pick a challenge.
3. Choose models for one or both seats.
4. Step a single model move or auto-run a full model-vs-model match.
5. Review the leaderboard for wins, losses, draws, illegal moves, and logic accuracy.

For chess, install Stockfish separately and configure `stockfish_path` if you want engine evaluations.

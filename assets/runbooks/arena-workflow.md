# Model Arena workflow

1. Open the Arena toolbar chip or an `*.nj-arena.json` file.
2. Pick a challenge (Connect Four, chess, or logic), or open the **Benchmark** tab.
3. For a match: choose models for one or both seats, then kick off / auto-run.
4. For a benchmark: multi-select installed Ollama models, pick a suite (`quick` or `logic-only`), then Run.
5. Review the benchmark scoreboard (pass rate, logic accuracy, Connect Four completion) and the Standings leaderboard for wins, losses, draws, illegal moves, and logic accuracy.

For chess, install Stockfish separately and configure `stockfish_path` if you want engine evaluations.
